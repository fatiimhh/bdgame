#   Gotham: Bat Signal Chronicles 🦇 ------ https://fatiimhh.github.io/bdgame/

A cinematic 2D Batman-inspired game built with **Phaser 3 + Vite**.  
You play as Batman completing missions across Gotham rooftops, detective systems, high-speed pursuits, and a final defense of the Bat Signal.

---

##  Gameplay Overview

The game is split into multiple narrative-driven levels:

###  Rooftop Exploration
- Collect glowing Bat Signals across Gotham rooftops  
- Smooth movement, dash system, and rain ambience  
- Atmospheric parallax skyline of Gotham City  

###  Detective Mode
- Investigate crime scenes using Batcomputer analysis  
- Choose correct clues to unlock the next mission  
- Cinematic UI with typewriter effects  

###  Pursuit Level
- Chase a moving target across rooftops  
- Jump, platform, and avoid losing the target  
- Time-based challenge with increasing tension  

###  Final Level
- Defend the Bat Signal from incoming enemies  
- Survive waves until Gotham is safe  
- Cinematic ending sequence with narration + visuals
